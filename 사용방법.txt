비밀 공부 일기 — 김민솔

실행
1. index.html을 Chrome 또는 Edge에서 엽니다.
2. 비밀번호를 두 번 입력해 일기장을 만듭니다.
3. 과목, 범위, 전체 분량, 시험 날짜, 한 단위당 공부 시간을 입력합니다.
4. 오늘의 컨디션과 시간을 입력하면 오늘 계획이 나옵니다.
5. 공부한 항목을 체크하고 일기를 저장합니다.

직접 열었을 때 암호화 기능이 지원되지 않는다면:
이 폴더에서 터미널을 열고 아래 명령을 실행합니다.
python -m http.server 8000 --bind 127.0.0.1
브라우저에서 http://localhost:8000 을 엽니다.
종료: 터미널에서 Ctrl+C
파일로 열기와 localhost로 열기는 저장 공간이 다릅니다. 계속 같은 방식으로 접속하세요.

간단한 구현 방식
- 외부 라이브러리, 서버, AI API가 없는 HTML 파일 하나입니다.
- 한 번에 시험 하나를 관리합니다. 새 시험을 시작해도 지난 일기는 남습니다.
- 오늘 분량 = 남은 분량 / 남은 공부일 × 컨디션 비율을 올림한 값입니다.
  시간으로 가능한 분량과 전체 남은 분량을 넘지 않도록 제한합니다.
- 좋음 1.2, 보통 1, 피곤함 0.7 비율을 적용합니다.
- 각 체크 항목은 표시된 분량 전체를 완료했을 때 체크합니다.
- 일기를 저장하면 오늘 체크가 확정됩니다. 남은 전체 분량을 내일부터 시험 전날까지 균등 분배합니다.
- 다음 날 계획은 실제 남은 전체 분량에서 다시 계산합니다.
- 재분배 표는 미래에도 같은 공부 시간과 컨디션을 가정한 참고 계획이며, 처음 7일을 표시합니다.
- 일기 응원은 달성 여부와 일부 감정 키워드로 고르는 규칙 기반 문구입니다. 실제 AI를 사용하지 않습니다.
- 일기는 날짜별로 하나이며, 같은 날 다시 저장하면 수정됩니다.

저장 및 잠금
- 학습 정보와 일기 전체를 AES-GCM으로 암호화해 브라우저 localStorage에 저장합니다.
- 암호화 키는 비밀번호에서 PBKDF2(SHA-256, 250000회)로 만듭니다. 비밀번호 원문은 저장하지 않습니다.
- 새로고침하거나 다시 접속하면 비밀번호를 입력해야 합니다. 자리를 비울 때는 잠그기를 누르세요.
- 비밀번호 복구, 계정, 동기화, 백업 기능은 없습니다. 비밀번호와 브라우저 데이터를 잘 보관하세요.
